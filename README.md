## 🎯 Objective

To analyze customer shopping behaviour, identify purchasing patterns, and generate actionable business insights using data analytics and visualization.

## Project Overview

An end-to-end data analytics project focused on understanding customer shopping behaviour and purchasing patterns.

The project uses **Python, PostgreSQL, and Power BI** to clean, analyze, and visualize customer data and generate business insights.

### Key Highlights

- Analyzed **3,900 customer records**
- Examined customer demographics, purchasing patterns, categories, payment methods, discounts, subscriptions, and seasons
- Performed data cleaning and feature engineering using Python
- Integrated the cleaned data with PostgreSQL
- Created an interactive Power BI dashboard
- Identified key sales and customer behaviour trends

## Project Workflow

1. Data loading and inspection using Python
2. Data cleaning and preprocessing
3. Feature engineering
4. Exploratory data analysis
5. PostgreSQL database integration
6. SQL-based analysis
7. Power BI dashboard creation
8. Business insights and recommendations

## Key Insights

- Total purchase value: $233,081
- Average purchase amount: approximately $59.76
- Clothing generated the highest revenue.
- Fall recorded the highest revenue among seasons.
- Male customers represented approximately 68% of the dataset.
- Approximately 27% of customers had a subscription.
- PayPal had the highest number of customers among the payment methods.

## Power BI Dashboard

The project includes a Power BI dashboard showing:

- Total sales

- Category performance
- Age-group analysis
- Revenue by category
- Revenue by season
