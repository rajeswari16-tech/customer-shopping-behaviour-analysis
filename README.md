# Customer Shopping Behaviour Analysis

## Project Overview

This project analyzes customer shopping behaviour using Python, PostgreSQL, and Power BI.

The objective is to understand customer purchasing patterns, product categories, customer demographics, subscription behaviour, payment methods, and seasonal sales performance.

## Tools & Technologies

- Python
- Pandas
- NumPy
- PostgreSQL
- SQL
- Power BI
- Jupyter Notebook
- Excel

## Dataset

The dataset contains customer shopping behaviour information including:

- Customer ID
- Age
- Gender
- Category
- Purchase Amount
- Discount Applied
- Subscription Status
- Payment Method
- Season
- Review Rating
- Purchase Frequency

## Project Workflow

1. Data loading and inspection using Python
2. Data cleaning and preprocessing
3. Feature engineering
4. Exploratory data analysis
5. PostgreSQL database integration
6. SQL-based analysis
7. Power BI dashboard creation
8. Business insights and recommendations

## Key Insights

- Total purchase value: $233,081
- Average purchase amount: approximately $59.76
- Clothing generated the highest revenue.
- Fall recorded the highest revenue among seasons.
- Male customers represented approximately 68% of the dataset.
- Approximately 27% of customers had a subscription.
- PayPal had the highest number of customers among the payment methods.

## Power BI Dashboard

The project includes a Power BI dashboard showing:

- Total sales
- Customer count
- Subscription status
- Gender distribution
- Category performance
- Age-group analysis
- Revenue by category
- Revenue by season
